# Luma 1.0.0

The first stable GitHub release for **Windows 11 x64**.

- **Five languages:** English, Türkçe, Deutsch, Español and Italiano. New installations start in English. Change the language under **General → Language**; existing preferences keep their language during updates.
- **Live localization:** settings, first-run setup, installer, tray menu, audio controls and accessible labels follow the selected language. Track, app and device names stay unchanged; licenses retain their original text.
- **Everyday controls:** compact animated volume/brightness flyouts, audio output switching, per-app volume, media controls and source selection, blurred artwork, lock-key indicators, monitor selection, scaling, themes and colors.
- **Reliability:** the audio-panel close/reopen fix, atomic settings recovery, read-only live preview meters, manual verified downloads and update rollback remain included.

**272 automated Windows checks passed**, including language persistence/transfer, English first-run behavior, legacy settings migration, repeated language switching, minimum-size layouts and native audio-panel mouse input. The GitHub workflow separately validates all 264 keys in each translation catalog, compiles Windows binaries and checks distribution files/checksums.

## Install or update

Download **`Luma-1.0.0-Setup.exe`** below and choose **Install → Open Luma**. No administrator or separate .NET installation is needed. Luma is searchable from the Windows Start menu. Existing installed versions can also use **General → Check for updates → Download and update**. Your settings and startup choice are retained.

For portable use, extract **`Luma-1.0.0-win-x64.zip`** to a permanent folder and run `Luma.exe`. GitHub's Source code archives contain source, not the runnable app. Both distribution files include SHA-256 sidecars.

## Scope

The executable is currently **unsigned**; there is no Store or native ARM64 package. Hardware-specific brightness behavior, Bluetooth/USB hotplug, mixed DPI, sleep/resume, long sessions and assistive-technology coverage continue to be tracked. A Windows brightness panel may still flash briefly on some systems. The stable label does not certify every hardware combination.
