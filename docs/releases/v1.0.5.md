# Luma 1.0.5

Makes available updates easier to notice.

- Scheduled discovery sends one Windows notification for each new stable release. Clicking it opens General at the update section; it does not start a download or installation.
- Keeps the last announced version locally, so reopening Luma or checking the same release again does not repeat the notification. A later release can notify again.
- Manual checks keep their result in Settings. The existing tray dot, menu action and settings badge remain available when Windows suppresses notifications.
- Temporary metadata-check failures retry after one, five and fifteen minutes before returning to the normal six-hour schedule. Startup checking still begins after about fifteen seconds.
- Notifications follow the app language: English, Turkish, German, Spanish and Italian. Disabling automatic checks prevents new scheduled notifications; Store editions continue using Windows-managed updates.

## Downloads

- **Luma-1.0.5-Setup.exe**: per-user installer. Existing users can choose **General → Check for updates → Download and update** once to receive this notification behavior for future releases.
- **Luma-1.0.5-win-x64.zip**: portable application.
- Matching `.sha256` files for both assets.

Windows 11 x64; runtime included. GitHub packages are unsigned. Preferences and language are preserved. Windows notification settings govern whether a notification is displayed. Microsoft Store publication remains pending.

## Türkçe

Geçici bağlantı hatalarında daha erken tekrar denenir. Mevcut kullanıcıların bu davranışı sonraki sürümlerde alabilmesi için önce 1.0.5'e güncellemesi gerekir.
