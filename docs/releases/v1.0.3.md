# Luma 1.0.3

Quiet update indicators for the GitHub edition.

- Checks for stable releases about 15 seconds after startup and every six hours while Luma runs. Automatic checks are enabled by default and can be turned off under General.
- Shows a small green dot on the tray icon, an Update available tray action and a compact badge in Settings when a newer stable release is found.
- Both update actions open the existing update section. Checks do not steal focus, show repeated toasts, download packages or install updates.
- Manual and background checks share a request. A temporary network failure keeps an already verified update available.
- Download and update remains an explicit user action and retains package verification and preference preservation.
- Microsoft Store builds continue to use Store-managed updates without GitHub polling.
- Adds translations, scheduling/UI regression checks and updated privacy and usage documentation.

## Downloads

- **Luma-1.0.3-Setup.exe**: per-user installer. Existing users can choose **General → Check for updates → Download and update**.
- **Luma-1.0.3-win-x64.zip**: portable application.
- Matching `.sha256` files for both assets.

Windows 11 x64; the .NET runtime is included. GitHub builds are currently unsigned. Microsoft Store publication remains pending. Existing settings and language are preserved; the new automatic-check preference defaults to on unless changed.
