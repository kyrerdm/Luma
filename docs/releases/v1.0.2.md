# Luma 1.0.2

Media-key popups for keyboards without volume keys.

- Standard keyboard play/pause, next, previous and stop keys now reveal the media card when the player exposes a Windows media session.
- Keys keep their normal Windows/player behavior. Luma observes the press without sending another playback command.
- The card uses cached media immediately, refreshes track/playback details, and briefly waits for a session if playback is just starting.
- Holding a key does not generate repeated popup requests. Popups follow the existing timeout, pin and fullscreen preferences.
- Turning off the media card also turns off these media-key popups. No empty card is shown when no supported session is available.

## Downloads

- **Luma-1.0.2-Setup.exe**: per-user installer; existing users can also use **General → Check for updates**.
- **Luma-1.0.2-win-x64.zip**: portable application.
- Matching `.sha256` files for both assets.

Windows 11 x64; the .NET runtime is included. GitHub builds are currently unsigned. Updates preserve language and preferences. Microsoft Store submission remains separate and pending. Player and keyboard support depend on the Windows media/session events they expose.
