# Luma 1.0.1

Maintenance release and Microsoft Store preparation for Windows 11 x64.

- Adds MSIX packaging with the included .NET runtime, scaled icons and license notices.
- Separates Store-managed startup and updates from the GitHub installer/updater.
- Copies valid GitHub preferences into the Store edition once, preserving the original files and existing Store preferences.
- Makes the About release-history link work across distribution channels.
- Simplifies the English and Turkish README files and updates installation guides.
- Adds a privacy policy, listing text in five languages, Store artwork and owner publishing instructions.
- Extends distribution/migration checks and makes brightness/tray fixtures independent of old Turkish test preferences.

English remains the default for fresh installations. Turkish, German, Spanish and Italian remain available; updates preserve the existing language and preferences.

## Downloads

- **Luma-1.0.1-Setup.exe**: per-user installer with Start menu integration.
- **Luma-1.0.1-win-x64.zip**: portable application.
- Matching `.sha256` files for both assets.

The runtime is included. GitHub packages are currently unsigned. Quit any older running copy before opening a different installation.

## Store status and compatibility

This GitHub release is not a Microsoft Store publication. The real owner/package identity, packaged installation/update/uninstall tests, Windows App Certification Kit and Microsoft review remain prerequisites for Store submission. Development-identity MSIX files are not public installation assets and must not be submitted to Store.

Brightness depends on display/driver support; Windows' native brightness indicator can briefly appear. Media controls depend on Windows sessions exposed by the player; browser tabs can share one session. Broader physical hardware, long-session and assistive-technology validation remains documented in the repository.
