# Luma 1.0 — quick start

[Download / İndir / Herunterladen / Descargar / Scarica](https://github.com/kyrerdm/Luma/releases/latest)

## English

Windows 11 x64. Download `Luma-1.0.3-Setup.exe` from Assets, run it and choose **Install → Open Luma**. No administrator or separate .NET installation is needed. Search for **Luma** in Start. Click the tray icon once for Settings. English is the default; change it under **General → Language**. Updates keep your selected language. The executable is currently unsigned.

## Türkçe

Windows 11 x64. Assets bölümünden `Luma-1.0.3-Setup.exe` dosyasını indir, çalıştır ve **Install → Open Luma** seç. Yönetici izni veya ayrı .NET kurulumu gerekmez. Başlat menüsünde **Luma** ara. Ayarlar için tepsi simgesine bir kez tıkla. Yeni kurulum İngilizce açılır; **General → Language → Türkçe** yoluyla değiştir. Güncelleme mevcut dil seçimini korur. Dosya henüz dijital imzalı değildir.

## Deutsch

Windows 11 x64. Lade `Luma-1.0.3-Setup.exe` unter Assets herunter, starte die Datei und wähle **Install → Open Luma**. Administratorrechte oder eine separate .NET-Installation sind nicht nötig. Suche im Startmenü nach **Luma**. Ein Klick auf das Symbol im Infobereich öffnet die Einstellungen. Wähle **General → Language → Deutsch**; danach heißt der Bereich **Allgemein → Sprache**. Updates behalten deine Sprachauswahl. Die Programmdatei ist derzeit nicht digital signiert.

## Español

Windows 11 x64. Descarga `Luma-1.0.3-Setup.exe` desde Assets, ejecútalo y elige **Install → Open Luma**. No necesitas permisos de administrador ni instalar .NET por separado. Busca **Luma** en Inicio. Haz clic una vez en el icono de la bandeja para abrir los ajustes. Elige **General → Language → Español**; después el campo se llama **Idioma**. Las actualizaciones conservan el idioma elegido. El ejecutable aún no tiene firma digital.

## Italiano

Windows 11 x64. Scarica `Luma-1.0.3-Setup.exe` da Assets, eseguilo e scegli **Install → Open Luma**. Non servono diritti di amministratore né un'installazione separata di .NET. Cerca **Luma** nel menu Start. Fai clic una volta sull'icona nell'area di notifica per aprire le impostazioni. Scegli **General → Language → Italiano**; in seguito la sezione si chiama **Generali → Lingua**. Gli aggiornamenti mantengono la lingua scelta. L'eseguibile non ha ancora una firma digitale.

## Portable

Download `Luma-1.0.3-win-x64.zip`, extract it to a permanent folder and open `Luma.exe`. The .NET runtime is included. Exit from the tray menu before replacing a portable copy. GitHub's Source code archives contain source, not the runnable application.
